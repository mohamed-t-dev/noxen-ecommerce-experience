# Noxen Studio

An editorial e-commerce concept for a fictional home-fragrance brand. The project combines product discovery, interactive storytelling, cart state, responsive navigation, and accessible UI controls in a polished React experience.

> Portfolio concept: Noxen is a fictional brand. Products, prices, account access, newsletter submission, and checkout behavior are simulated.

## Highlights

- Responsive product catalog with selectable featured products
- Cart drawer with quantity controls and calculated totals
- Interactive ritual selector and product-story sections
- Mobile navigation, account dialog, and newsletter feedback states
- Keyboard-friendly controls, labels, and dialog semantics
- Cloudflare-compatible static delivery configuration

## Technology

- React 19
- Vite
- JavaScript
- CSS
- Phosphor Icons

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run test:sites
```

## Project status

Front-end portfolio demonstration. Authentication, payments, and order processing are not connected to production services.
